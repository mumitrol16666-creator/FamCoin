# FamCoin

Мобильный финансовый трекер с ИИ-консультантом для Казахстана. iOS и Android, русский и казахский языки. Код выполняет учёт и расчёты; ИИ объясняет результаты и помогает с вводом.

## Как запустить

Нужен только Docker Desktop. Всё остальное — база, сервер и приложение — собирается в контейнерах.

```bash
docker compose up -d --build
```

- Приложение: http://localhost:3000
- API: http://localhost:8080/health

Нажмите «Создать аккаунт», введите email и пароль (от 8 символов) — аккаунт откроется сразу, затем анкета из 8 шагов. Три неверных пароля подряд блокируют вход на 15 минут на сервере. Тариф Pro в разработке включается переключателем в настройках.

Остановить и снова запустить:

```bash
docker compose down
```

Данные остаются в томе `pgdata` и переживают перезапуск. Полностью очистить базу: `docker compose down -v`.

### Развёртывание на сервер

Нужен сервер с Docker и доступ по SSH. Скрипт копирует код, при первом запуске создаёт `.env` с паролем базы, собирает образы на сервере и перезапускает контейнеры:

```bash
deploy/deploy.sh root@95.216.145.108
```

Наружу смотрит Caddy (80/443) с автоматическим сертификатом Let's Encrypt для домена из `.env` (`PUBLIC_URL=https://coin.edudev.kz`). Приложение — https://coin.edudev.kz, API — `/api`, установщик Android — `/download/famcoin.apk`. Настройки продакшена — в [docker-compose.prod.yml](docker-compose.prod.yml).

**Android.** `deploy/deploy.sh root@95.216.145.108 --android` дополнительно собирает подписанный APK в контейнере с Flutter и Android SDK (на Mac ничего ставить не нужно) и выкладывает его по `/download/famcoin.apk`. Ключ подписи создаётся один раз в `/opt/famcoin/keys` — без него обновления поверх установленной версии не встанут, папку нужно беречь и копировать вместе с бэкапами.

Логи на сервере: `ssh root@95.216.145.108 'cd /opt/famcoin && docker compose logs --tail 100'`.

**Резервные копии.** Ежедневно в 03:00 `deploy/backup.sh` делает дамп базы в `/opt/famcoin/backups` (хранится 14 дней). Если в `.env` заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT`, копия уходит файлом в Telegram. Восстановление: `deploy/restore.sh <файл.sql.gz>`.

**Админка.** http://95.216.145.108/api/admin/ — пароль в `ADMIN_PASSWORD` в `.env` на сервере (создаётся при первом деплое). Пользователи, разблокировка, сброс пароля, тариф, удаление, статистика, журнал действий.

**Уведомления и Telegram.** Сервер в 8:00 и 21:00 по времени Казахстана формирует утреннюю сводку и вечерний отчёт для каждого пользователя. Они видны в приложении («Ещё → Уведомления»); при заданном `TELEGRAM_BOT_TOKEN` пользователь привязывает бота кодом и получает их в Telegram.

### Разработка без пересборки контейнера

Для быстрой правки приложения удобнее запускать его с Flutter SDK (`brew install --cask flutter`), оставив базу и сервер в Docker:

```bash
cd app && flutter run -d chrome
```

Макет ключевых экранов открывается прямо в браузере:

```bash
open design/mockup/index.html
```

Тесты ядра и приложения:

```bash
cd packages/famcoin_core && dart test && cd ../../app && flutter test
```

Для сборок под iOS нужен Xcode, под Android — Android Studio с SDK; после установки проверить `flutter doctor`.

## Продукт

- **Обычная версия — бесплатно:** ручной учёт, один денежный счёт, лимиты на две категории, долги, цели, поиск, базовые отчёты и экспорт.
- **Pro — 10 000 ₸ в год:** несколько счетов, дополнительные лимиты, чеки, шаблоны, расширенные отчёты и консультант с квотами. Голосовой ввод — в обычной версии, распознавание на устройстве без ИИ.
- **Семейный учёт ведёт один пользователь.** Члены семьи — справочник для распределения расходов и доходов.
- **RU / ҚАЗ с первой версии:** интерфейс, категории, ошибки, уведомления, голос и ответы ИИ.
- История хранится за весь срок использования; переход между тарифами сохраняет данные.

## Принципы ядра

- Суммы — целые тиыны (`BIGINT`), никаких float. В интерфейсе ориентиры округляются до целого тенге.
- Журнал двойной записи: у каждой операции дебет равен кредиту, несбалансированная запись не проводится ни одной стороной.
- Перевод, выдача долга, тело кредита и резерв цели — не расход. Рассрочка — расход на полную сумму в дату покупки и долг; её выплаты не создают второго расхода.
- Повтор команды с тем же ID не создаёт дубль; исправление — отменяющая запись, история сохраняется.
- Агрегаты по дням — восстановимая проекция, совпадающая с журналом до тиына.

## Технологическая основа

Сервер — **PostgreSQL 18.6** (актуальный стабильный выпуск на 22 сентября 2026 года; перед развёртыванием версия проверяется повторно). Клиент — Flutter с зашифрованной локальной SQLite/SQLCipher. Подробности — в [архитектуре хранения](docs/architecture/data-storage.md). Сервер хранит журнал владельца в PostgreSQL и проверяет каждую команду ядром `famcoin_core`. Работы без сети и локальной SQLite пока нет: приложению нужна связь с сервером.
