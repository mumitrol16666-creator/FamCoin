# Сторис FamCoin

Анимированные ролики 9:16 (1080×1920) из HTML-сцен: слова, счётчики и экраны
приложения анимируются CSS, `render.mjs` покадрово снимает сцену в headless
Chrome (протокол DevTools, без npm-пакетов) и собирает MP4 через ffmpeg.

- `scripts.md` — тексты для озвучки и раскадровка серии;
- `story.css`, `engine.js` — общий стиль и движок (`seek(t)` для покадрового рендера);
- `storyNN.html` — сцена конкретной сторис; открыть с `?play` — просмотр в браузере, `?t=12.5` — кадр;
- `sfx.py` — звуковой дизайн: синтез эффектов (свист, щелчки счётчика, монета, удар, нарастание, касание, перезвон, фон) по подсказкам `<script id="sfx">` в сцене; лицензии не нужны;
- `out/` — готовые ролики (в git не попадают).

Правило текста: надписи на экране — без точки в конце. С озвучкой эффекты автоматически приглушаются, пока звучит голос.

```bash
node render.mjs story01.html out/story01.mp4 20            # без звука
node render.mjs story01.html out/story01.mp4 20 30 01.m4a  # с озвучкой
STILLS="2,8,15" node render.mjs story01.html /tmp/kadry   # отдельные кадры для проверки
```

Цифры на экранах — демонстрационные; личные данные пользователей в сцены не попадают.
