## Часть 2. Операции, связи и формулы

### 2.1 Сущности и связи

```
Пользователь ─┬─ Пространство (личное / семейное) ─┬─ Участники (роль)
              │                                     ├─ Счета ──── Операции
              │                                     ├─ Категории ─┘  │
              │                                     ├─ Бюджеты/Лимиты ┘ (по категории/счёту/участнику)
              │                                     ├─ Цели ◄──── Переводы в цель
              │                                     ├─ Долги ◄─── Выдача / Погашение
              │                                     └─ Регулярные платежи ──► генерируют Операции
```

Правило модели: **баланс счёта нигде не хранится как отдельное поле**. Он всегда вычисляется из операций, а для скорости кешируется. Поэтому данные не могут разойтись.

### 2.2 Виды операций

| # | Тип | Счёт | Влияет на расходы/доходы | Связь | Пример |
|---|---|---|---|---|---|
| 1 | **Расход** | −счёт | Расход | Категория, лимит | Магнум 8 400 ₸ |
| 2 | **Доход** | +счёт | Доход | Категория дохода | Зарплата 450 000 ₸ |
| 3 | **Перевод** | −счёт A, +счёт B | ❌ нет | Два счёта | Kaspi → депозит |
| 4 | **Обмен валюты** | −KZT, +USD | ❌ (разница курса пишется отдельно) | Курс | 100 000 ₸ → $190 |
| 5 | **Пополнение цели** | −счёт, +цель | ❌ (это накопление) | Цель | Отпуск +20 000 |
| 6 | **Снятие из цели** | +счёт, −цель | ❌ | Цель | |
| 7 | **Дал в долг** | −счёт | ❌ (актив «мне должны») | Долг | Асхату 30 000 |
| 8 | **Взял в долг** | +счёт | ❌ (обязательство) | Долг | |
| 9 | **Возврат долга мне** | +счёт | ❌ | Долг | |
| 10 | **Я вернул долг** | −счёт | ❌ | Долг | |
| 11 | **Получение кредита** | +счёт | ❌ (обязательство) | Кредит | |
| 12 | **Платёж по кредиту** | −счёт | **Проценты и комиссии = расход**, тело = погашение долга | Кредит | 52 000 = 40 000 тело + 12 000 % |
| 13 | **Покупка в рассрочку** | 0 сразу | Расход на **всю сумму** в дату покупки | Рассрочка | Телефон 240 000 (0-0-12) |
| 14 | **Платёж по рассрочке** | −счёт | ❌ (погашение) | Рассрочка | 20 000/мес |
| 15 | **Возврат покупки** | +счёт | Уменьшает расход категории | Исходная операция | |
| 16 | **Кешбэк / бонусы** | +счёт | Доход «Кешбэк» | Счёт | Kaspi бонусы |
| 17 | **Проценты по депозиту** | +счёт | Доход «Проценты» | Депозит | |
| 18 | **Корректировка баланса** | ± | ❌ по умолчанию | Счёт | Сверка наличных |
| 19 | **Разделённая операция** | −счёт | Расход по нескольким категориям | Одна родительская | Чек: продукты + бытовая химия |

**Ключевое правило:** перевод, долг, цель и тело кредита — это движение денег, а не расход. Поэтому аналитика показывает, сколько вы реально потратили, и не завышает траты, как многие трекеры.

### 2.3 Формулы

Обозначения: Σ — сумма, д — дни, м — месяцы.

**Балансы и капитал**
```
Баланс счёта        = Начальный остаток + Σ входящих − Σ исходящих
Ликвидные деньги    = Σ балансов (наличные + карты + текущие счета)
Активы              = Ликвидные + Депозиты + Цели + Инвестиции + «Мне должны»
Обязательства       = Σ остатков кредитов + рассрочек + кредиток + «Я должен»
Собственный капитал = Активы − Обязательства
```

**Бюджет месяца**
```
Доход месяца          = Σ операций «Доход» (без переводов)
Расход месяца         = Σ «Расход» + проценты по кредитам
Сальдо                = Доход − Расход
Норма сбережений %    = (Доход − Расход) / Доход × 100
Обязательные платежи  = Σ регулярных платежей + платежи по кредитам/рассрочкам в месяце
Свободные деньги      = Ожидаемый доход − Обязательные − План накоплений
```

**«Можно потратить сегодня»** — главная цифра
```
Доступно = Ликвидные − Оставшиеся обязательные до след. дохода − Оставшийся план накоплений
Дней     = Дата следующего дохода − Сегодня  (минимум 1)
Сегодня  = Доступно / Дней − уже потрачено сегодня
```
Считаем до следующей зарплаты, а не до конца месяца: так точнее при зарплате 10-го числа.

**Лимиты**
```
Использовано %         = Потрачено в категории / Лимит × 100
Прогноз на конец      = Потрачено / Прошло дней × Дней в периоде
Риск превышения       = Прогноз > Лимит → предупреждение заранее
Остаток в день        = (Лимит − Потрачено) / Оставшиеся дни
```
Уведомления при 80% и 100%, плюс раннее предупреждение по прогнозу.

**Методы бюджета**
```
50/30/20:        Нужное = 0.5 × Доход,  Желания = 0.3 × Доход,  Накопления = 0.2 × Доход
Конверты:        Доход − Σ конвертов = 0  (не распределено должно быть 0)
Сначала себе:    Накопление = Доход × p%  → остальное свободно
```

**Цели**
```
Прогресс %        = Накоплено / Целевая сумма × 100
Нужно в месяц     = (Целевая − Накоплено) / Месяцев до срока
Прогноз даты      = Сегодня + (Целевая − Накоплено) / Средний взнос за 3 мес.
Копилка-округление = ceil(Сумма / Шаг) × Шаг − Сумма   (шаг 100 / 500 / 1000 ₸)
```

**Кредиты (аннуитет, как у большинства банков РК)**
```
r         = Годовая ставка / 12
Платёж    = S × r × (1+r)^n / ((1+r)^n − 1)
% в месяц = Остаток × r
Тело      = Платёж − % в месяц
Переплата = Платёж × n − S
```
Дифференцированный платёж: `Тело = S/n`, `% = Остаток × r`. Для сравнения предложений показываем ГЭСВ (годовую эффективную ставку вознаграждения), как требует регулятор РК.

**Досрочное погашение**
```
Уменьшить срок:  n' = −ln(1 − Остаток×r/Платёж) / ln(1+r)
Уменьшить платёж: Платёж' = аннуитет(Остаток − Досрочно, r, n_осталось)
Экономия = Переплата_до − Переплата_после
```

**Стратегии погашения долгов**
```
Снежный ком: сортировка по остатку ↑   (быстрые победы, мотивация)
Лавина:      сортировка по ставке ↓    (минимальная переплата)
Свободные деньги сверх минимальных платежей → первому долгу в списке
```

**Финансовое здоровье (0–100)**
```
Долговая нагрузка (ПДН) = Платежи по долгам в месяц / Доход × 100    (норма < 30%, риск > 50%)
Подушка, мес            = (Ликвидные + Депозиты) / Средние обязательные расходы  (норма 3–6)
Норма сбережений        = см. выше                                   (норма ≥ 10–20%)

Здоровье = 0.35 × Балл(сбережения) + 0.35 × Балл(подушка) + 0.30 × Балл(ПДН)
```
ПДН (показатель долговой нагрузки) — это термин Нацбанка РК, пользователю он знаком.

**Аналитика**
```
Среднее в день            = Расход периода / Дней
Отклонение от нормы %     = (Факт месяца − Среднее за 3 мес) / Среднее за 3 мес × 100
Аномалия                  = Факт категории > Среднее + 2σ
Доля категории %          = Категория / Расход × 100
Прогноз остатка на конец  = Ликвидные + Ожидаемые доходы − Обязательные − Среднее в день × Оставшиеся дни
```

**Мультивалютность**
```
Всё приводится к основной валюте (KZT) по курсу на дату операции
Курсовая разница = Остаток_вал × (Курс_сегодня − Курс_покупки)  (отдельная строка, не расход)
```

### 2.4 Особенности Казахстана
- **Рассрочки 0-0-12 / 0-0-24** (Kaspi, Halyk) — отдельный тип, без процентов, с графиком.
- **Kaspi Red, кредитные карты** — лимит, льготный период, минимальный платёж.
- **Чеки ОФД**: QR-код на чеке ведёт к полному чеку с позициями. Используем его вместо распознавания фото (OCR), это точнее.
- **Депозиты**: ставка + капитализация + отметка о гарантии фонда КФГД.
- **Зарплата**: ввод «на руки» или «грязными» с расчётом ОПВ 10%, ИПН 10% и ВОСМС 2%.
- **Валюта**: ₸ с разделителем тысяч пробелом: `1 250 000 ₸`.
