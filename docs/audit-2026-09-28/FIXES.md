## Что осталось на следующий этап

- Экспорт CSV/бэкап для пользователя, корзина с восстановлением.
- PIN/биометрия и защищённое хранилище сессии (`flutter_secure_storage`) для нативных сборок.
- Порционная загрузка журнала, серверные итоги, ограниченный кеш — для многолетней истории.
- Ошибки ядра приходят готовыми русскими фразами; для казахского нужны коды ошибок.
- Прогон на реальных iPhone/Android: клавиатура, «назад», фон, VoiceOver/TalkBack. Android-сборка в Docker на ARM-Mac не проходит из-за CMake x86_64; на x86-сервере (`deploy.sh --android`) собирается.
- Для App Store: альтернативная регистрация без Telegram, покупка через App Store (сборка `STORE_BUILD=true` уже скрывает кнопку Stars).
